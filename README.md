# As Crônicas de Cob: A Jornada pela Modernização

Apresentação interativa em estilo mangá que conta a história da transformação da cobrança do Banco Pan através do ecossistema Cobdesk.

## 🎯 Acesse a Apresentação

👉 **[Clique aqui para ver a apresentação ao vivo](https://anderson-cmyk.github.io/apresentacao-cobdesk/)**

## 📖 Sobre

Esta é uma experiência web interativa dividida em três partes:

1. **O Mangá** - A Saga do Inovador (narrativa visual em formato webtoon)
2. **O Dojo de Inovações** - Experiência gamificada para desbloquear as ferramentas Cobby
3. **O Portal** - Convite para experimentar o Cobdesk ao vivo

## 🚀 Tecnologias

- HTML5
- CSS3 (animações e transições)
- JavaScript (interatividade)
- Design responsivo
